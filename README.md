# Data Wrangling and Visualisation in R

## Project Overview

This project focuses on data wrangling, data cleaning, transformation, and visualisation using R. It demonstrates the application of various functions and packages to prepare, manipulate, analyse, and visualise datasets.

## Objectives

The main objectives of this project are to:

- Identify and handle missing values.
- Calculate summary statistics using grouping and summarising functions.
- Transform datasets between wide and long formats.
- Create and modify variables using conditional statements.
- Apply functions across rows and columns.
- Filter, arrange, and manipulate datasets.
- Create visualisations using `ggplot2`.

## Tools and Packages

The project uses R and the following packages:

- **dplyr** – Data manipulation and transformation.
- **tidyr** – Data reshaping and cleaning.
- **ggplot2** – Data visualisation.
- **purrr** – Functional programming and applying functions to data.

## Project Contents

The repository contains R scripts and exercises covering different data wrangling and visualisation techniques.

## Skills Demonstrated

- Data cleaning and preparation
- Handling missing data
- Data transformation and aggregation
- Working with grouped data
- Functional programming
- Data visualisation using ggplot2
